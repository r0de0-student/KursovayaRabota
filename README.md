# Goodlyfe Gyms 

Адаптивный веб-сайт фитнес-клуба, разработанный в рамках курсовой работы по дисциплине «Информационные системы и технологии».

Проект представляет собой одностраничный лендинг (Landing Page), сверстанный на основе предоставленного макета с использованием современных технологий веб-разработки.

## ✨ Функционал

### Основные секции:
1. **Шапка сайта (Header)** — логотип, навигационное меню, кнопка поиска и входа.
2. **Hero-блок** — фоновое изображение с призывом «Welcome to Coollyfe Gyms» и кнопкой действия.
3. **Meet your new body** — блок с текстовым описанием и стеком перекрывающихся изображений.
4. **Real Stories from Real Customers** — карточки с отзывами клиентов и бейджами потерянных килограммов.
5. **Don't forget our app** — секция мобильного приложения с кнопками скачивания и мокапами телефонов.
6. **Social** — иконки социальных сетей (Facebook, YouTube, Instagram).
7. **Футер (Footer)** — колонки с быстрыми ссылками, руководствами, контактами и копирайтом.

### Динамические эффекты (JavaScript и CSS):
- **Анимация при скролле:** элементы плавно появляются при прокрутке страницы.
- **Модальные окна:** вход и регистрация с валидацией полей и приветственными уведомлениями.
- **Уведомления (Toast):** всплывающие сообщения при клике на кнопки (успех, ошибка, информация).
- **Кнопка «Наверх»:** появляется при прокрутке > 300px и плавно возвращает в начало.
- **Hover-эффекты:** трансформация карточек, телефонов, социальных иконок и кнопок.
- **CSS-анимации:** пульсация кнопки, покачивание телефонов, плавное появление (`@keyframes`).

## 🛠 Технологии
- **HTML5** — семантическая разметка (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3** — Flexbox, позиционирование, `border-radius`, градиенты, медиа-запросы.
- **JavaScript (Vanilla JS)** — работа с DOM, обработка событий, создание модальных окон и уведомлений.
- **Адаптивность** — медиа-запросы для планшетов (до 768px) и телефонов (до 480px).

## ⚙️ Установка и запуск

Проект не требует сборки или установки зависимостей.

1) Скачай папку с проектом.
2) Открой файл index.html в любом современном браузере (Chrome, Firefox, Edge, Яндекс.Браузер).
3) Для работы всех функций (например, скачивания шрифтов или иконок) рекомендуется использовать локальный сервер, например, расширение Live Server в VS Code.



## 💡 Пара советов

1. **Картинки:** Убедись, что все картинки (`1.png`, `2.png`, `Hero Slider.png` и т.д.) лежат в той же папке, что и `index.html`. Если ты закинешь их в репозиторий, сайт будет работать корректно при клонировании.
2. **GitHub Pages:** Ты можешь легко опубликовать этот сайт бесплатно! Зайди в настройки репозитория (Settings) -> Pages -> Build and deployment -> Source: Deploy from a branch -> Branch: main / root. Через пару минут появится ссылка на твой рабочий сайт, которую можно вставить в README вместо заглушки "Демо".
3. **Скриншоты:** Добавь пару скриншотов в README (например, вид на ПК и вид на телефоне). Это сильно украсит репозиторий.
